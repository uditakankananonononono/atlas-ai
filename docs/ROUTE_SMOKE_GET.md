## WIP26 m20 service scoping and alias (what is and is not claimed)
- Clean alias /api/v1/modules/20/... is an ASGI path rewrite to the legacy /api/v1/api/modules/20/... (outermost middleware), so handlers, require_tenant and rate limiting are identical. Legacy path unchanged. NOT listed in OpenAPI; only the m20 prefix is aliased (inner doubled segments remain). Exact-segment match (/modules/2000 stays 404).
- Service scoping: bind_service(svc, tenant_id=X) serves only X. bind_service(svc) (legacy) is SHARED: served to all tenants outside production; in production refused (503) unless ATLAS_GCW_SINGLE_TENANT equals the request tenant. Unbound: per-tenant in-memory default, finite cap 64, fail closed (503, no eviction, no silent deletion). No request tenant (outside a request) fails closed. Tenant contextvar is set/reset per request by a yield dependency.
- NOT claimed: production-ready tenant isolation. In dev mode the tenant is header-trusted (test mode). CognitiveWorkerService internals are not thread-safe (the lock covers default-service creation only). Not persistent; multi-worker inconsistency unproven. Health capability value None = unknown, not false.
