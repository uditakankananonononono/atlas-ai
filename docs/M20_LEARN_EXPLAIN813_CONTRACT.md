# LEARN-EXPLAIN813: rows813/814 structured explanation practice

Candidate SCOPED unit for independent audit, not broad elaboration/self-explanation.
Existing method routes now require provenance-bound symbolic fact/rule records
and a target. Legacy prompt fields remain for compatibility; those prompts alone
are not the executed capability. Execution means target-specific symbolic
practice generation and submitted-step evaluation, not proof that learning occurred.

The finite positive Horn model has0..64 supplied facts and1..64 rules, each with
a bounded source identifier. Rules have unique IDs, <=64 premises and one
conclusion; no negation/unless or NL rule extraction. Source identifiers are
caller-bound references, not fetched URLs or independent truth verification.
Least-fixed-point closure determines target entailment and a canonical ordered
proof restricted to target ancestors. Alternative valid derivations are accepted
in submitted attempts. Unsupported cycles derive nothing. If the target cannot
be derived, status is target_not_entailed, not a fabricated explanation.

Elaborative interrogation generates a target-specific why/prerequisite task,
a derivation, and recomputes entailment after removing each supplied fact. These
are single-fact counterfactual sensitivity checks, not all minimal sufficient
premise sets or causal effects in the real world. A redundant fact may be removed
without blocking the target. Self-explanation uses the same supplied model for
step-specific explanation practice. The two modes are explicit, not distinct
unvalidated cognitive scoring algorithms.

Up to100 evidence-bound attempts, each <=64 ordered steps, are checked against
the actual registered rule ID, exact conclusion and premise set, and availability
of premises at that step. Invalid steps do not add their conclusions. Feedback
reports missing prerequisites, mismatched rule/conclusion/premises and source;
an attempt passes only if every step is valid and the target is reached. Retry
recommendation follows failure; improved_from_previous means only a failed
supplied attempt followed by a passing attempt in input order. It is not causal
proof of teaching effect, chronological timestamp inference or measured mastery.
All attempt IDs are unique; malformed records refuse with no input mutation.

Mounted authenticated existing learning-reasoning routes inherit tenant payload
binding/cross-tenant resource rejection. No persistence, retrieval, effects,
models or scheduling are added. Synthetic held-out chains, alternate proofs,
wrong rules/premises/conclusions, out-of-order steps, fact removal, cycles and
retry outcomes are tested. Free-text explanation semantics, understanding,
transfer to arbitrary domains and educational effectiveness remain unclaimed.
