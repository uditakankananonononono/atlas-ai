## Delta against the existing mechanism

This unit (new files, shared cluster file untouched) differs in three ways: exact decimal arithmetic on decimal strings (64 significant digits, outputs rounded half-even to 9 places); sigma estimated from the average moving range, sigma = MRbar/1.128 (individuals chart), so a large outlier does not inflate its own limits the way an all-points standard deviation does; and an added 8-in-a-row flag on one side of the centre line. ## Mechanism
`chart_baseline(payload)` in `backend/app/modules/m20_general_cognitive_worker/statistical_process_control1536.py`. Input `{series_id, values}`; any other key refuses. `series_id` is non-blank text of at most 128 characters (checked first), then Unicode-checked: no Unicode control, line/paragraph separator or bidi/format characters (categories Cc, Zl, Zp, DEL, and the format characters U+200B-200F, U+202A-202E, U+2066-2069, U+FEFF); ordinary spaces and printable non-ASCII are allowed. Refusal `invalid_series_id` names the field, never the value. `values` is 2..500 strings (the 500 cap is stricter than any 1000 cap). Each number must fully match `^-?(0|[1-9][0-9]*)(\.[0-9]+)?$` in ASCII: no exponent, inf, nan, plus sign, leading zero, whitespace or underscore. Checks run on the text before any Decimal operation, in this order: length <= 80 (`number_too_long`), shape (`invalid_number`), at most 64 significant digits counted from the first nonzero digit and at most 64 fraction digits (`number_precision`; a number not exactly representable is refused, never rounded), then |v| <= 10^12 by exact `copy_abs` compare (`number_range`). Refusal text is `SPC1536: <code>: <message>` and never contains the input. Output: n, center_line (mean), moving_range_mean (mean of |x[i]-x[i-1]|), sigma_hat = MRbar/1.128, ucl and lcl = centre line +/- 3 sigma, and `flags`, sorted by index then rule: `beyond_lcl` (x < lcl), `beyond_ucl` (x > ucl; a point equal to a limit is not flagged), `run8_above` / `run8_below` (the point completes eight consecutive points strictly above / below the centre line; a point on the centre line breaks the run). A constant series gives sigma 0 and no flags. Labels: baseline_only true, control_state_claimed false, process_intervention_advised false.

## Arithmetic context
Input is exact: parsed numbers are never rounded. Derived values (mean, moving-range mean, sigma, limits) are 64 significant digits rounded, not exact, then output rounded half-even to 9 places. All arithmetic runs in a fully specified local context (prec 64, ROUND_HALF_EVEN, Emin -999999, Emax 999999, capitals 1, clamp 0, traps InvalidOperation, DivisionByZero, Overflow, Underflow; Inexact is not a trap) so the ambient decimal context cannot change output or verdicts. A trapped condition is refused as `SPC1536: arithmetic: computation could not complete`, never a raw decimal exception. Flags are 64-digit-rounded comparisons: this unit makes no exactness claim for a flag decided at the last digit.
