# Group 90 structured product evidence

Adds deterministic structured extraction to the existing source-span teardown:
explicit delimited ingredient/composition/material lists, founded-by/in-year facts,
and numeric commission percentages. SHA-256 source text and exact start/end/quote
are retained per record. Multiple founder/year/ingredient-list variants produce
unresolved disagreement records; none is silently chosen as truth.

Three new tests reproduced missing-module red before implementation, then passed:
structured facts/exact spans/disagreements, absent commission numeric data and
out-of-range percentage refusal, source-instruction inertness. Full c32 plus
prior group execution selection: 335 passed. Fixtures are supplied texts, not
independent brand research or live API behavior.

Limits: regex extraction only, may miss context or group product variants as
conflicts. No chemical safety, affiliate eligibility, enrollment, business results,
autonomous Pinterest browsing or universal market analysis. c30 HARD_REFUSE remains
unchanged. Automatic collection remains unimplemented; no official API integration executed.
Tool-fetched public text may be supplied as evidence, but this function never
fetches. Source text is untrusted data and cannot authorize effects. Group 90
remains PARTIAL, not verified brand intelligence.
