# Atlas full-fidelity direction

Modules 0-6 are production work, not placeholders. The binding direction is the original specification plus the owner's September 20 expansion. Each named capability must be implemented or tracked with an honest blocked reason. "Implemented" means real provider/API/browser/database/worker behavior with tests, not a stub, simulation, pseudocode, or scaffold.

## Non-negotiable safety and accuracy

- Official API first. Public pages only when allowed. Login-gated sources use the owner's authorized session at human speed with cadence logs and immediate throttle/challenge backoff.
- No Discord self-bots. Use invited official bots/webhooks.
- No piracy or OceanofPDF collection. Use legal publisher, library, Crossref, OpenAlex, arXiv, PubMed/PMC, DOAB, Project Gutenberg, and user-owned documents.
- Never fabricate application activities. Atlas may retrieve real activities, angle truthful evidence, identify gaps, and propose real activities to complete before a deadline.
- External messages, follow-ups, publishing, form submission, deletion, and payment always pass Module 0 with the final recipient/account/content visible.
- Google Docs/Sheets are read-only grounding unless the owner approves the exact quoted material and application use.
- Cross-model critique means deliberate GPT/Claude/Gemini rounds with convergence and cost limits, not repetitive 50x loops.
- Every metered high-scale crawl or compute job exposes cost/cadence/keyword/source limits before launch.

## Module 1 source model

Configurable registries own: official RSS/APIs; public allowed sites; user-authorized browser accounts; custom webhooks; scholarship site seeds; social account seeds; keywords. User-named Instagram scholarship/opportunity/admissions/research/business accounts belong in the seed registry. The requested target of exactly 200 scholarship sites is enforced as a completeness target; missing entries remain explicit and are never invented. The requested 10,000+ keywords and large account universe are configuration/data, not hard-coded loops.

Kaggle uses its official API. Unstop and similar sites use the owner's logged-in browser session, default three checks/day, adjustable only with account-safety review. LinkedIn/Instagram/X/YouTube use official APIs where available and authorized human-speed browser reads otherwise. Discord uses invited bots/webhooks, never self-bots.
