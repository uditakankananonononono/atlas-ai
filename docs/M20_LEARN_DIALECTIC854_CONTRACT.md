# M20 DIALECTIC854/INTEGRATE855 scoped contract

Finite explicit feature/value reasoning only. The schema declares1..32 features and1..16 unique values each. Frames declare1..16 sourced unique IDs, each with0..32 sourced allowed-value constraints. Claims declare1..128 sourced feature/value statements tied to known frames; assumptions declare0..128 sourced feature/value statements. Evidence IDs are unique across both banks. Claims disagree when a schema feature has two or more supplied values, including within a single frame. Sources are labels, not independently verified truth.

Up to128 caller-supplied resolutions name a schema feature/value,1..64 premise IDs from either evidence bank,1..128 claim IDs they resolve, and their own source. Unknown/duplicate references refuse. A supported resolution requires an actual conflict, at least one agreeing same-feature premise, no contrary same-feature premise, every conflicting claim covered, and no included claim on another feature. Premises on unrelated features neither support nor contradict that value. No inference rule language or invented synthesis. Assumptions can support a candidate but are not established facts.

Integration additionally checks the candidate value against every same-feature constraint in every supplied frame. Missing constraints do not invent restrictions. All constraints must allow it. Multiple supported resolutions with different values remain unresolved even when individually supported; no majority, averaging or silent winner. No conflicts returns no_conflicts; any unresolved feature returns no_supported_resolution; all conflicts individually resolved without competition returns supported_resolution. Reports preserve supported and refused candidates, premise/source traces, uncovered/wrong-feature claims, violated frames and competing resolutions.

Dialectic and integration share validation and conflict detection; only integration applies frame restrictions. They are restricted computations, not general philosophical reasoning, novel synthesis, truth checks or real-world conflict resolution. No effects, persistence or learned reasoning. Minimal payloads refuse; mounted authentication/tenant boundaries remain.
