## Mechanism
`gauge_rr_study(payload)` in `backend/app/modules/m20_general_cognitive_worker/measurement_systems_analysis1538.py`. Input `{study_id, measurements: [{part, operator, values: [decimal strings]}]}`: 4..1000 cells, 2..50 parts, 2..20 operators, every part x operator cell present exactly once, every cell with the same 2..20 repeats, each value finite with |v| <= 10^12. Mean squares: part, operator, interaction, error (df p-1, o-1, (p-1)(o-1), po(r-1)). Components: repeatability = MS_error; interaction = (MS_int - MS_err)/r; operator = (MS_op - MS_int)/(p r); part-to-part = (MS_part - MS_int)/(o r). A negative estimate is reported as 0 and named in `truncated_components` (an estimate exactly 0 is not truncated). reproducibility = operator + interaction; gage_rr = repeatability + reproducibility; total = gage_rr + part-to-part. Output also the standard deviations and percent contribution (repeatability, reproducibility, gage_rr, part_to_part, of the total variance). A study with no variation refuses. Label gauge_approval_claimed false.

## Input grammar, text fields and arithmetic context
Input is exact: parsed numbers are never rounded. Every measurement value must fully match `^-?(0|[1-9][0-9]*)(\.[0-9]+)?$` in ASCII (no exponent, inf, nan, plus sign, leading zero, whitespace or underscore). Checks run on the text before any Decimal operation: length <= 80 (`number_too_long`), shape (`invalid_number`), at most 64 significant digits from the first nonzero digit and at most 64 fraction digits (`number_precision`, refused never rounded), then |v| <= 10^12 by exact `copy_abs` compare (`number_range`). Text fields `study_id`, `part` and `operator` are non-blank text of at most 128 characters (checked first), then Unicode-checked: no Unicode control, line/paragraph separator or bidi/format characters (categories Cc, Zl, Zp, DEL, and the format characters U+200B-200F, U+202A-202E, U+2066-2069, U+FEFF); ordinary spaces and printable non-ASCII are allowed. Refusals `invalid_study_id`, `invalid_part`, `invalid_operator` name the field, never the value; the duplicate-cell refusal no longer echoes the part and operator. The 1000-record cap is unchanged. Refusal text is `MEASYS1538: <code>: <message>`; structural messages (payload, counts, balance, zero variation) have no code and are unchanged.
Derived values (means, sums of squares, variance components, deviations, percentages) are 64 significant digits rounded, not exact, then output rounded half-even to 9 places. All arithmetic runs in a fully specified local context (prec 64, ROUND_HALF_EVEN, Emin -999999, Emax 999999, capitals 1, clamp 0, traps InvalidOperation, DivisionByZero, Overflow, Underflow; Inexact not a trap), so the ambient context cannot change output. A trapped condition is refused as `MEASYS1538: arithmetic: computation could not complete`, never a raw decimal exception. The truncation of negative variance estimates to zero and the zero-total check compare 64-digit-rounded values: no exactness claim is made at the last digit.
