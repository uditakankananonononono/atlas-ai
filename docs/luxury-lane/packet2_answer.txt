Additional bugs and caveats
Unused variable: brand_terms = set() never removes anything. The comment about excluding brand names is misleading; brand names remain in the term set if tokens() includes them.
Potential batch failure: check_ideas() uses asyncio.gather() without exception handling around each task. A malformed idea can cause the whole batch call to fail, despite fetch errors being handled inside check_idea().
Weak URL construction: Wikipedia titles are not properly URL-encoded. Replacing spaces with underscores does not correctly handle all title characters.
Markdown injection / formatting corruption: Evidence quotes, mechanisms, source titles, and URLs are inserted into Markdown without escaping Markdown syntax. HTML values are escaped, which is good, but the two formats can render materially different content.
Unchecked input contracts: Required fields such as idea_id, mechanism, evidence, scores, and source_ids are indexed directly. Missing or incorrectly typed fields can produce runtime failures.
No independent proof of safety: external_action_started: False is a returned constant, not evidence that no external action occurred elsewhere. The function itself does not send anything, but the broader claim depends on the surrounding system.
