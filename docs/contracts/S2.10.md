# S2.10 / c33.niches - Viral-niche generator

## Source pin
Verbatim excerpt: "Create new, viral apps, contents, trends etc on thousands and millions of niches".

## What it does
Enumerates niches as taxonomy x audience x format over SUPPLIED vocabularies, scores each as supplied trend minus supplied competition, ranks deterministically (score desc, name tiebreak), reports the computed count.

## What it does not do
"Millions of niches" is enumeration capacity only; no virality guarantee. Scores come from supplied numbers, not live trends.

## Refusals
SOCIAL_REFUSED_OVERSIZE (combos > MAX_NICHES or vocab > MAX_VOCAB), SOCIAL_REFUSED_EMPTY:*, SOCIAL_REFUSED_DUPLICATE:*, SOCIAL_REFUSED_BAD_TYPE:*, SOCIAL_REFUSED_CONTROL_CHARS:*, SOCIAL_REFUSED_TEXT_TOO_LONG:*.

## Limits
MAX_NICHES = 10000; MAX_VOCAB = 64 per axis. IC: niche name template, score model (trend - competition) and caps are interpretation choices.
