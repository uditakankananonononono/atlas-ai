# S2.12 / c33.persona - Persona-per-field voice profiles

## Source pin
Verbatim excerpt: "replicate human essence and personality into individual fields as suitable".

## What it does
Voice/tone profiles per field from SUPPLIED writing samples: average sentence length, formal/informal/neutral tone from marker counts, top content words. Output carries a not-impersonation guidance line.

## What it does not do
Never impersonates a real person (SOCIAL_REFUSED_IMPERSONATE). "Human essence" is not claimed: profiles are surface style features only.

## Refusals
SOCIAL_REFUSED_IMPERSONATE, SOCIAL_REFUSED_EMPTY:samples, SOCIAL_REFUSED_OVERSIZE, SOCIAL_REFUSED_BAD_TYPE:*, SOCIAL_REFUSED_CONTROL_CHARS:*, SOCIAL_REFUSED_TEXT_TOO_LONG:*.

## Limits
MAX_SAMPLES = 256; sample <= 50000 chars; top 5 words. IC: stopword list, formal/informal markers, feature set and the real_person trigger are interpretation choices.
