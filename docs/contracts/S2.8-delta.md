# S2.8-delta / c32.thought_chains - evidence-bearing reasoning-move analyzer

Extends c32.thought (frozen: `thought.py`, `analyze(texts)`, its tests and `docs/contracts/S2.8.md` are unchanged). New module `backend/app/modules/c32/thought_chains.py`, entry `run(request)`; `analyze_v2` is the same function (alias).

## Source scope
This module covers supplied transcripts, text and lyrics only. Its design rules are spec-author scope, not evidence of owner-channel approval. It is not a QA1535 requirement/test-observation evaluator, an audio transcriber or a model of human thought.

## What it does
Input `{"docs":[{"id","kind","medium","text","turns"?,"segments"?}]}`; `kind` in transcript|text|lyrics (default text); `medium` is required and must be one of: podcast, audiobook, book, article, essay, speech, lecture, interview, lyrics, poem, other. Caps: 10000 docs, 200000 chars per text, id 64, label 64, speaker 64 raw characters. Request document text totals at most 5000000 characters; duplicate references count repeatedly.
Per doc: word count, sentence count, per move `hits` (every surviving cue occurrence), `sentences_with_move`, `per_1000_words` (rounded 6 places, 0.0 for zero words); up to 5 evidence spans per move `{doc, offset (sentence start in text), sentence}`; sentence-based `chains`, `transitions`, `longest_run`; `excluded_hits` {negated, quoted}; `unmatched_quote_marks`; `legacy_comparison` (per-move counts using c32.thought's own MOVES table and counting expression, which keeps lyrics with newlines comparable; analyze() itself refuses newlines). Corpus: move totals, transitions, by_kind and by_medium pooled rates, media list, scope, `report_caveat`, `validity`.
Matching: word-boundary only, no stemming. Words = `re.findall(r"[^\W_]+(?:'[^\W_]+)*", sentence.lower())`. Sentences end at `.`/`!`/`?` followed by whitespace or end, or at any newline.
Cue lists (frozen, contiguous word sequences):
- analogy: like a, like an, as if, similar to, reminds, reminded, reminding
- first_principles: first principles, first principle, fundamental, fundamentals, from scratch, why is, why are
- heuristic: rule of thumb, rules of thumb, usually, tends to, tend to, tended to, as a rule
- inversion: opposite, opposites, in reverse, instead, backwards
- narrative: story, stories, journey, journeys, once, chapter, chapters
- systems: feedback, loop, loops, system, systems, emerges, emerge, emerging, network, networks
Negation: "not", "no", "never" or a word ending in "n't" within the 3 words immediately before the first word of the cue, same sentence, excludes the cue (`negated`). Quotes: from a straight `"` to the next `"`, or `\u201c` to `\u201d`; no nesting; cues inside are excluded (`quoted`, which wins when a cue is also negated); an unmatched or stray quote mark opens no span and counts in `unmatched_quote_marks`. Curly apostrophes are not word characters inside words (`don\u2019t` is two words).
Moves in a sentence are ordered by the first surviving cue position, ties by move name. Transitions: consecutive distinct moves within a sentence, plus last move of a tagged sentence to first move of the next tagged sentence (untagged sentences between do not break the link). `longest_run` = longest run of consecutive tagged sentences.
Turns `[{speaker, text, t_start?}]` and segments `[{label, text}]` are annotations that must partition `text` exactly (concatenation, no separator, no normalization) else BAD_SEGMENT. Speaker must be an exact string, capped before stripping. Blank after stripping gives bare NOSPEAKER; non-string gives BAD_TYPE:speaker. `t_start`, if given, is a finite int/float >= 0 (seconds, bool refused), non-decreasing. A cue is attributed to the turn or segment containing its first word.

## Report caveat (template, exact)
This analyzer tags reasoning-move cues using a fixed word list. Counts show where cues appear in the supplied text, not whether anyone reasoned well or originally. Precision and recall are agreement with synthetic labels written for this fixture, not validation of human thinking. Audio is not transcribed. Only the media supplied are covered: {media}.

The report renders `{media}` with the sorted, de-duplicated medium labels present in the request.

## Owned input preflight
Every supplied dictionary, list, string and timestamp has an exact built-in type requirement: dict, list, str, and int/float respectively (bool and subclasses refused). Lists do not accept tuples. Optional turns/segments and t_start may be absent or None, preserving the delta's optional-field behavior.

Allowed dictionary keys: request `{docs}`; doc `{id, kind, medium, text, turns, segments}`; turn `{speaker, text, t_start}`; segment `{label, text}`. Unknown or non-exact-string keys are refused without echoing them. Each dictionary has a 16-key cap checked before key iteration. Container refusal suffixes are request, docs, turns or segments. This strict schema belongs only to `run`/`analyze_v2`; legacy `thought.analyze()` is untouched.

Turns and segments have separate caps of 1000 entries per doc and 20000 entries per request per kind. List lengths are checked before iteration. A raw preflight over the whole request checks types, sizes, running document-text total and annotation counts before any document Unicode scan, strip, cue regex, analysis or partition comparison. Entry-text lengths are summed incrementally; first excess over document length refuses BAD_SEGMENT without processing later entries. Partition equality is checked incrementally with startswith, never by allocating a concatenated string. No text normalization occurs.

Echoed id/label/speaker fields refuse Unicode Cc/Cf/Zl/Zp with BAD_TYPE:<field>; Zs is allowed. Document text retains the existing shared-helper Cc/Zl/Zp rule, with ordinary LF/CR/TAB allowed as before. All existing id/text/label raw length caps are checked locally before calling the shared helper. Shared c30.policy is unchanged.

## Refusals
Size/count: `TREND_REFUSED_OVERSIZE:<field>` (docs, text, id, label, speaker, turns, segments, request). Type/shape: `TREND_REFUSED_BAD_TYPE:<field>` (request, docs, turns, segments, id, kind, medium, text, speaker, label, turn_text, segment_text, t_start). Invalid enum values use BAD_TYPE:kind/medium without echoing values. Other refusals: EMPTY:docs|text|id|label, bare NOSPEAKER, AUDIO, BAD_SEGMENT, CONTROL_CHARS:text. Codes have no supplied key/value/index/count appended.

## Limits
Rule and word-list based; six moves; surface cues only. Cue presence does not show that anyone reasoned well. No audio and no ASR (audio kind is refused). No claim covers "all forms" of media; the report lists the media supplied. Interpretation choices: medium required, kind defaults to text, duplicate doc ids allowed, `legacy_comparison` as described above.

## Pure-offline applicability note
None of the six standing rules (spend, outreach, fakeacct, autopost, scrape, trade) has a code path here: the module only reads the supplied dict and returns a dict. A test asserts that the module exposes only `run` and its alias and no function named for spending, sending, posting, trading, fetching or account creation. The c30 helper is used for `clean_text` and `scope` only.
