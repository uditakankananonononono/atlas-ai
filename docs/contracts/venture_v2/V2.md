# V2: patents

Source pin (requirement text from supplied spec, not independent permission evidence): "see new ideas/ventures and develop its own patent applications".

Routes: POST /api/v1/c37/patents/run and GET /api/v1/c37/patents/report.

## Implemented
Prior-art corpus ranking and owner-invention claim draft with source mapping.

Inputs and outputs: see scripts/venture_v2/hand_battery.py and audits/venture_v2/hand-results.json. Inputs carry sources with unique id + public URL and explicit as_of. Reports include computed coverage, as_of, scope, and source metadata.

## LIMITS
No live patent-provider search, legal novelty opinion, application completeness or filing. Supplied sources, license metadata and baseline outputs are not independently authenticated by this engine. Synthetic fixtures are not claims about real occupations, inventions, papers or competing products.

Claim classification: SUBSTITUTE. No complete-aspiration claim. External model facade review: PENDING.
