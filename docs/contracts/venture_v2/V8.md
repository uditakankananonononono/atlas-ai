# V8: news-create

Source pin (requirement text from supplied spec, not independent permission evidence): "make sure any thing interesting news or paper or new scifi tech etc formed research on it etc create something new".

Routes: POST /api/v1/c37/news-create/run and GET /api/v1/c37/news-create/report.

## Implemented
RSS/Atom intake, URL dedupe, interest/novelty heuristic, research briefs and experiment tickets.

Inputs and outputs: see scripts/venture_v2/hand_battery.py and audits/venture_v2/hand-results.json. Inputs carry sources with unique id + public URL and explicit as_of. Reports include computed coverage, as_of, scope, and source metadata.

## LIMITS
No live news fetch, peer-review verification, autonomous invention or hardware creation. Supplied sources, license metadata and baseline outputs are not independently authenticated by this engine. Synthetic fixtures are not claims about real occupations, inventions, papers or competing products.

Claim classification: IMPLEMENTED-BOUNDED. No complete-aspiration claim. External model facade review: PENDING.
