Validation order: exact request dict; complete shape/key/resource admission; known raw-field caps; recursive forbidden scan; unknown keys; date/top-level types/empty; scalar schema fields and item hygiene in row order; computation. This explicitly supersedes forbidden-first wording for hostile malformed shapes. Nested dict keys under idea fields refuse UNKNOWN:<constant field> before scalar type validation. Non-string keys refuse BAD_TYPE:key before forbidden scan. Key hygiene occurs before normalization. Forbidden normalization is casefold and hyphen to underscore, exact table membership. Tables provide constant suffixes only.
