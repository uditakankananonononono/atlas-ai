# S1.2 capability-replication-planner (c31.replicate_plan)

Source pin (verbatim, spec S1.2): "replicate them and integrate into atlas"; "actually integrate it into themselves if its opensource of build it into themselves if itsnt".

Does: emits one deterministic build ticket per (tool, capability) pair from
SUPPLIED capability-matrix records, acceptance-tests-first flagged on every
ticket. Routing by license: open licenses (mit/apache/bsd) => "integrate";
anything else (gpl/proprietary/unknown) => "build_ourselves".
Does not: replicate or integrate anything live, and never copies
closed-source behavior: copy_closed=True against a non-open license refuses.
Refusals: FLEET_REFUSED_NOSOURCE / OVERSIZE (>4096) / BAD_TYPE:tool|capabilities /
BAD_LICENSE:<license> / UNLICENSED (closed-source copying) / plus c30
clean_text codes on name, capability (<=128 chars).
Limits: MAX_TOOLS 4096; tickets sorted by (capability, tool).
IC: gpl is treated as non-open for the integrate route (conservative reading
of "if its opensource"); the verbatim source grammar is preserved as written.
