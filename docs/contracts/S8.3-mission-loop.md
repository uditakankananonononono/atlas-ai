## API
`run(request)` returns a plain dict or raises ValueError. Stdlib runtime; imports real policy.clean_text and policy.scope. No init/policy/HTTP/catalog changes.

Request keys: as_of clean string, required seed exact integer0<=seed<2**63, required budget, experiments list, runners dict of named trusted callables, optional prior_log list. Unknown keys refuse. Budget max_experiments exact integer>=1, max_total_seconds finite positive number, optional max_cash exact numeric zero (bool refused). Experiments require unique id, nonblank hypothesis, nonempty unique tags, expected_metric exactly{name,direction}, runner name, declared_seconds finite positive number, effect="none", optional finite priority default0. Directions higher/lower. Numeric metrics accept finite int/float except bool and are rendered as floats rounded6 places.

Prior rows have exactly id,as_of,outcome,metric_name,direction,metric_value,tags,error,order_index. Index is nonnegative exact integer. Success has finite metric and null error; failure has null metric and string error<=200; skipped_budget has null metric/error. Duplicate terminal(id,as_of) refuses. Prior rows are validated then copied, not trusted as verified evidence.

Ordering is fixed once per cycle: any tag lacking a prior terminal row first, then priority descending/id ascending. Seed is used only by a shared isolated Random passed sequentially to runners. No epsilon or exploitation. Callers supply deterministic pure fixtures. Copies protect caller experiment/log structures from ordinary mutation, not from arbitrary malicious callables.

Success/failure suppress same(id,as_of); budget skips may retry. Every non-suppressed considered item appends exactly one new record, continuing prior maximum index+1. Returned prior prefix is copied unchanged. Declared budgets count started calls including failures, skip items that cannot fit and continue to cheaper items. Tag counts describe current request/cycle: defined, current successes/failures/skips and untried excluding suppressed terminal experiments. Historical successful metrics contribute stats grouped by(tag,name,direction), never mixed scales; lower chooses minimum as best. "tried N of M defined experiments" reports current calls, not historical cumulative success.
