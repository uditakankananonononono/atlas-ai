# S1.7 deploy-1000-builders (c31.deploy)

Source pin (verbatim, spec V2-1 fleet scaling): "build thousands of real business, running real operations by themselves... Have 1000s of workers (like all of the above) working on this".

Does: plans a fleet of up to 1000 SUPPLIED synthetic builder jobs (the list is supplied, never generated here; 1000 is the cap, not a guarantee):
deterministic role assignment (6-role cycle), waves under a global
concurrency cap (actual concurrency = min(requested, job count)), per-wave
cost accounting, total cost.
Does not: execute any job, run any business, or operate autonomously; this
is a deterministic plan over supplied jobs.
Refusals: FLEET_REFUSED_SPEND (spend=True) / OVERCAP:<n>>1000 / EMPTY:jobs /
BAD_TYPE:jobs|job|cost|concurrency / DUPLICATE:<job_id> / CONTROL_CHARS:job_id.
Limits: FLEET_SIZE 1000 (the source's canonical fleet); cost >= 1 per job;
job_id <= 64 chars.
IC: "thousands of businesses" is realized as the 1000-job fleet plan the
spec names; autonomy and real operations stay out of scope.
