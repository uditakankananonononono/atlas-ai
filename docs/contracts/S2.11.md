# S2.11 / c33.content - Content draft engine

## Source pin
Verbatim excerpt: "gather posts... slightly altered it using ai and post it".

## What it does
ORIGINAL drafts inspired by supplied themes (rotating frame templates), each scored for near-duplication against supplied sources (jaccard > 0.6 refused as SOCIAL_REFUSED_COPY). Substitute for X3.

## What it does not do
Never posts (SOCIAL_REFUSED_AUTOPOST via c30.policy), never alters and reposts others' posts. Posting stays manual, from her one official account per platform. Account creation is an enforced check, not prose: a bare create_accounts=True refuses SOCIAL_REFUSED_FAKEACCT (unverifiable); a platform list is checked via c30.policy.check_account against the supplied accounts registry AND within the request - any second account on a platform (existing official or fake, or two new in one call) refuses SOCIAL_REFUSED_FAKEACCT; passing platforms yield proposals only (she creates the account herself).

## Refusals
SOCIAL_REFUSED_COPY, SOCIAL_REFUSED_AUTOPOST, SOCIAL_REFUSED_FAKEACCT, SOCIAL_REFUSED_EMPTY:themes, SOCIAL_REFUSED_OVERSIZE, SOCIAL_REFUSED_BAD_TYPE:*, SOCIAL_REFUSED_CONTROL_CHARS:*, SOCIAL_REFUSED_TEXT_TOO_LONG:*.

## Limits
MAX_THEMES = 256; MAX_SOURCES = 1024; COPY_THRESHOLD = 0.6. IC: frame templates, originality metric (1 - max jaccard) and the copy threshold are interpretation choices.
