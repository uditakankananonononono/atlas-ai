# S7.2 paper-trading backtester

Status IMPLEMENTED-BOUNDED.
Walk-forward, OHLC, costs and metric rules are bounded design choices.
This is offline simulation only, no permission to trade, spend or send.

## Interfaces

app.modules.m20_general_cognitive_worker.s72_paper.run(request, *, strategy=None)
returns a plain dict. strategy is a trusted host callable(history)->target_weight
in [0,1] (not bool), long-only, fractional shares. Default is cash. HTTP never takes
source code or callbacks; only cash, buy_hold, moving_average_5 built-in IDs.

Exact supplied bars: date/open/high/low/close. Strict YYYY-MM-DD increasing dates,
positive finite prices within [1e-9,1e12], low<=min(open,close)<=max<=high. No symbol
universe, dividend adjustment, volume, corporate actions or stale quote checking.
Config: initial_cash positive [1e-9,1e12], fee_bps/slippage_bps [0,9999],
periods_per_year integer1..10000, explicit as_of string. No wall clock.

For bar i, strategy gets only completed bars[:i], immutable dicts, not future bar.
Target from prior close is executed on bar i open with adverse proportional
slippage, percentage fee on executed value. Target weight is measured against
post-fee equity at fill. Buy quantity=(w*equity_at_fill-existing_value)/(fill*(1+w*f));
sell quantity=(existing_value-w*equity_at_fill)/(fill*(1-w*f)). No loans, shorts or
leverage. Rebalance every new bar; no terminal liquidation. Equity marked at close.
Turnover=sum(abs(shares_traded)*unadjusted_open)/initial_cash. Brier not computed
here. Drawdown=max((peak-equity)/peak). Sharpe=mean(period_returns)/sample_stdev
*sqrt(periods_per_year), risk-free0, no frequency inference. Under2 returns or
stdev<=1e-12 yields null Sharpe. Negative equity refuses rather than hiding loss.

Each history attempt beyond available bar/slice flags LOOKAHEAD; flag checked even
if callback swallows IndexError. Identical prefixes are evaluated twice; unequal
weights refuse nondeterminism. This is a finite deterministic check, not proof.

## J1 only

Optional forecast_predictions/forecast_resolutions supplied together. The lazy
relative import .j1_forecast.score_predictions is the ONE scorer, with bins10 and
calibrated=True defaults, forwarded forecast_bins/forecast_calibrated if supplied.
No local Brier, reliability or hit-rate implementation. Unavailable J1 refuses
MONEY_REFUSED_DEPENDENCY. J1 errors retain INTEL_* or canonical POLICY_* prefix.
No runtime stub or fallback result. Delegation tested with a host test double to
prove arguments; real J1 import remains an integration gate until J1 is composed.
The caller supplies forecast outcomes, S7.2 does not infer them from strategy P&L.

## Safety, routes, refusals

All reports: "not financial advice, simulated, past results". action=trade,
order_route or broker hard-refuses MONEY_REFUSED_TRADE; spend refuses SPEND;
guarantee_profit=True refuses GUARANTEE. Any other non-false guarantee flag refuses
SCHEMA. Nothing can add a broker adapter from request data. Unknown actions go
through canonical c30.policy.check(...,'MONEY'), deny-only. Simulation classifies
an offline module20/analyze descriptor with canonical c30.policy; no local adapter.

MONEY_REFUSED_{NODATA,SCHEMA,STRATEGY,LOOKAHEAD,NUMERIC,DEPENDENCY} cover input,
callback, numerical and missing-J1 failures. Success never grants money authority.
Optional router prefix /api/v1/c36/paper with POST /run and GET /report. Host mounts
s72_paper_routes.router and bind_paper_tenant for authenticated tenant selection.
At most128 bound tenants, latest-only ephemeral report, deep-copy isolation.
No main.py edits; trusted host config, host request-byte/rate limits still required.

## LIMITS

2..10000 bars, long-only single series, fractional fills with unlimited liquidity.
No realistic exchange mechanics, volume constraints, taxes, dividends, capital gains,
borrow costs, market impact, spread, data cleaning, train/validation optimization or
strategy parameter fitting. Walk-forward means chronological prefix execution,
not a claim to rolling model training or out-of-sample statistical validity.

TRUSTED-CODE ONLY. Python callbacks can read global future data, inspect objects,
mutate their own state, make external calls or hang. There is no hostile-code
sandbox, network barrier or timeout for arbitrary host callbacks. Prefix guard
only prevents ordinary access via supplied history; external closure/global leaks
are not caught. API uses only fixed in-repo callbacks, not user-submitted Python.
Built-ins deliberately simple, not investment recommendations or validated profit.
User-provided OHLC, costs, sources and forecasts are not independently verified.
Past performance and returned Sharpe never guarantee profits or future skill.
