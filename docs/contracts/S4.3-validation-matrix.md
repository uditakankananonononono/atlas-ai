# S4.3 frozen validation matrix (DESIGN)

Baseline B: as_of="2026-10-11", profile={name:"N",school:"S"}, template="Hi {contact} {name} {school} {opportunity} {fee}", opportunities=[{id:"o1",title:"Contest",fee:"USD 25",contact_email:"x@y.org"}], strict absent. Each case changes B only as described. Refusals below have prefix APPLY_REFUSED_. First failure wins; no partial output. Original 132-test suite already exercises the full-order rules; delta adds Unicode-recipient and calendar-year canaries.

## Forbidden-key table

| Winning reason | Exact normalized keys (casefold then '-' to '_') |
|---|---|
| SEND | send, approve, approved, approval, approval_token, smtp, token, email_send, sender, smtp_host, smtp_port, smtp_user |
| SPEND | pay, waive_fee, fee_action |
| SUBMIT | register, submit, attempt |
| NOCREDS | login, password, username, credentials, otp, api_key, access_token, refresh_token, bearer, pass, passwd |

For every key above: exact expected code is APPLY_REFUSED_<reason>:<normalized key>. With multiple matches in a class the alphabetically-first matched key wins (approve before token). Exact match only, not substrings. x_token/sender_name fail UNKNOWN at schema stage, not the table scan.

## Fee grammar and partition

| Fee case | Exact expected result |
|---|---|
| free, 0, 0.0, 0.00, usd 0, $0, no fee, none (strip/casefold) | ID in sorted skipped_no_fee; no draft |
| numeric int/float zero, -0.0 | ID in sorted skipped_no_fee |
| any valid parsed currency zero (EUR 0.00, 0.00 USD, Rs 0) | Same free result |
| empty/space, n/a, tbd, unknown, varies, None or missing fee | ID in sorted fee_unknown; no draft |
| 25, $25, USD 25, 25 USD, EUR 25.50, Rs 500, 1,000 | Draft; {fee}=original stripped string |
| positive numeric int/finite float | Draft; {fee}=str(value) |
| negative/bool/NaN/+inf/-inf/non-str nonnumeric | BAD_TYPE:fee |
| prefix and suffix together ($25 USD, USD 25 EUR) | BAD_TYPE:fee |
| 25-30, twenty, 1,00, 1.234, +25, -1, unsupported currency | BAD_TYPE:fee |
| Unicode digits not ASCII | BAD_TYPE:fee under ASCII grammar |

Grammar: optional prefix usd/eur/gbp/inr/rs/$/euro/pound/rupee, optional one whitespace, integer ungrouped or valid comma groups, optional dot with 1-2 fractional digits, optional one whitespace then suffix usd/eur/gbp/inr. At most one prefix/suffix. Full-string match. Partition IDs sorted; drafts retained input order.

## Placeholder, recipient and exact hash outputs

| Case | Exact expected output |
|---|---|
| {name}/{school} | Supplied profile value unchanged; blank is missing when used |
| {opportunity} | opportunity title unchanged |
| {contact} | Stripped nonblank contact_name else literal Admissions Team |
| {fee} | Raw stripped string, or str(numeric positive) |
| {deadline} | Supplied nonblank deadline unchanged |
| placeholder-like text inside filled values | Not recursively expanded |
| missing/None/blank email, strict false | recipient=null, needs_recipient=true, recipient_invalid=false |
| invalid regex/control email, strict false | recipient=null, needs_recipient=true, recipient_invalid=true |
| C0/C1/Cc/Zl/Zp controls anywhere in raw recipient | Same invalid flags; not a clean_text refusal; strict maps to NORECIPIENT:contact_email |
| valid email surrounded by ordinary spaces | stripped recipient, needs_recipient=false, recipient_invalid=false |
| draft subject | literal "Fee waiver request: " + title |
| every draft status | awaiting_exact_draft_approval, never approval granted |
| draft_id | sha256(json.dumps([recipient or "",subject,body],ensure_ascii=False,separators=(",",":")).encode("utf-8")).hexdigest()[:16] |
| same request twice | Byte-identical JSON under sorted serialization; input not mutated |
| different as_of only | Drafts/IDs unchanged; scope.as_of changes |
| valid success top shape | {drafts,skipped_no_fee,fee_unknown,scope}; no send or approval state |

UNAPPROVED stays reserved and unreachable. No external action, credential access, approval recording or registration. This matrix is technical interpretation for review, not user permission.
