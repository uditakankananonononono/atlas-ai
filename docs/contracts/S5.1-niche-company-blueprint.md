## What the code does
`run(request) -> dict` in backend/app/modules/c36/blueprint.py. Pure, offline, deterministic, stdlib plus `app.modules.c30.policy.clean_text` and `policy.scope`. It does not call `policy.check`.
Input: {as_of: YYYY-MM-DD, niches: [{id, name, audience, problem, price_points, currency, regulated_flags, channels, worker_roles}]}.
- regulated_flags: list of non-blank str, each <= 50; flags are never interpreted. currency: None or str (non-str -> BAD_TYPE:currency); the 3-uppercase-letter check runs only when price_points is non-empty (bad format -> BAD_TYPE:currency); with empty price_points a bad-format string is ignored and never echoed. Roles match exactly (case-sensitive, no trim).
- B1: any regulated_flags -> `regulated_review_needed`, no blueprint, counted. All regulated -> VENT_REFUSED_REGULATED:niches.
- B2: offer = `<name>: <problem> for <audience>`.
- B3: price_points passed through (floats rounded to 6 places) with currency; none -> `pricing_missing`.
- B4: edges researcher->analyst, analyst->writer, writer->critic, critic->auditor, builder->critic, only when both roles are supplied. Other roles are isolated nodes. No transitive edges.
- B6: kpis visitors, trial_starts, purchases, retention_rate, each target null.
- B7: scaffold {README.md, plan.md, kpis.csv ("kpi,target\n")}. No code.
Permitted output containers (exact keys, no other extras): worker_graph {nodes, edges, isolated}; regulated_review rows {id, status}; pricing {status, price_points, currency}.
Output {blueprints, regulated_review, coverage{niches_supplied, blueprints_built, regulated_review_count}, scope}, sorted by niche id.

## Refusal table (ValueError, prefix VENT)
Order: dict -> forbidden-key scan (recursive) -> non-str key -> unknown key -> top-level types -> caps -> per-field -> compute.
SEND > SPEND > EFFECT > NOCREDS; first alphabetical match inside a class; key normalized by casefold and "-" to "_", exact match.
Reasons: CONTROL_CHARS (added by ruling (e)), REGULATED, EFFECT, SEND, SPEND, NOCREDS, UNKNOWN, OVERSIZE, BAD_TYPE, EMPTY, plus CONTROL_CHARS from clean_text. TEXT_TOO_LONG is unreachable (tested).
Suffixes are schema field names or matched table constants only.
Caps: niches 2000; id/name/audience/problem 200; price_points 20; channels 20; worker_roles 12; regulated_flags 10, each 50.

## LIMITS
