# S5.1 niche-company blueprint (c36.blueprint)

Design scope: implementation choices (a)-(g), with corrected choice (c). Build set B1, B2, B3, B4 (edges only), B6, B7. B5 funnel excluded.

Supplied requirement excerpt: "Autonomously build whole digital companies with autonomous worker ai bots across thousands of niches and lead the industries"
Source-message identity is not independently established by matching excerpt text. The design below narrows the quoted requirement to supplied-data bookkeeping.

## What the code does
`run(request) -> dict` in backend/app/modules/c36/blueprint.py. Pure, offline, deterministic, stdlib plus `app.modules.c30.policy.clean_text` and `policy.scope`. It does not call `policy.check`.
Input: {as_of: YYYY-MM-DD, niches: [{id, name, audience, problem, price_points, currency, regulated_flags, channels, worker_roles}]}.
- regulated_flags: list of non-blank str, each <= 50; flags are never interpreted. currency: None or str (non-str -> BAD_TYPE:currency); the 3-uppercase-letter check runs only when price_points is non-empty (bad format -> BAD_TYPE:currency); with empty price_points a bad-format string is ignored and never echoed. Roles match exactly (case-sensitive, no trim).
- B1: any regulated_flags -> `regulated_review_needed`, no blueprint, counted. All regulated -> VENT_REFUSED_REGULATED:niches.
- B2: offer = `<name>: <problem> for <audience>`.
- B3: price_points passed through (floats rounded to 6 places) with currency; none -> `pricing_missing`.
- B4: edges researcher->analyst, analyst->writer, writer->critic, critic->auditor, builder->critic, only when both roles are supplied. Other roles are isolated nodes. No transitive edges.
- B6: kpis visitors, trial_starts, purchases, retention_rate, each target null.
- B7: scaffold {README.md, plan.md, kpis.csv ("kpi,target\n")}. No code.
Permitted output containers (exact keys, no other extras): worker_graph {nodes, edges, isolated}; regulated_review rows {id, status}; pricing {status, price_points, currency}.
Output {blueprints, regulated_review, coverage{niches_supplied, blueprints_built, regulated_review_count}, scope}, sorted by niche id.

## Refusal table (ValueError, prefix VENT)
Order: dict -> forbidden-key scan (recursive) -> non-str key -> unknown key -> top-level types -> caps -> per-field -> compute.
SEND > SPEND > EFFECT > NOCREDS; first alphabetical match inside a class; key normalized by casefold and "-" to "_", exact match.
Reasons: CONTROL_CHARS (added by ruling (e)), REGULATED, EFFECT, SEND, SPEND, NOCREDS, UNKNOWN, OVERSIZE, BAD_TYPE, EMPTY, plus CONTROL_CHARS from clean_text. TEXT_TOO_LONG is unreachable (tested).
Suffixes are schema field names or matched table constants only.
Caps: niches 2000; id/name/audience/problem 200; price_points 20; channels 20; worker_roles 12; regulated_flags 10, each 50.

## LIMITS
No market validation, registration, payments, worker execution, funnel, scoring or recommendation. Counts are over the supplied list. Nothing here shows leading any industry.

## Uniform-policy delta (technical rulings, 2026-10-11)

Exact built-in dict/list/str/int/float caller types replace isinstance acceptance;
subclasses are refused with safe field-literal BAD_TYPE reasons. No initializer,
funnel, graph vocabulary, offer or KPI behavior is added. Existing B1-B4/B6/B7
is retained. Source pin provenance remains as stated in the original contract; design rules
are technical scope, not owner effect approval.

Validation now begins with count-first known-list preflight: niches2000,
price_points20, channels20, worker_roles12, flags10. Before recursive table scanning,
bounded iterative traversal counts container occurrences ONLY (dict/list/tuple),
maximum10000, root depth0 and maximum depth32 (scalar children included in depth).
Cycles refuse BAD_TYPE:request, resource overflow OVERSIZE:request. Shared acyclic
references may be traversed again and counted again; they are not falsely cycles.
A fully populated2000-item fixture may exceed the aggregate container budget; 2000
is a per-list limit, not a promise that every maximal shape fits every budget.

Schema keys raw200 before normalization/membership. Raw strings/currency/list leaves
are capped before table scanning/membership and clean_text: date raw10, currency
raw3 even if ignored with no prices, id/name/audience/problem/channel/role200,
flag50. Exceeding date10/currency3 yields OVERSIZE:as_of/currency, superseding earlier
BAD_TYPE overlong examples. Below cap, format still requires ASCII fullmatch
YYYY-MM-DD plus valid calendar, and nonempty prices require ASCII [A-Z]{3} currency
or None. Empty/invalid-format short currency can be ignored when prices empty,
but controls or oversize currency no longer bypass validation.

Text rejects full Cc/Cf/Zl/Zp categories, preserves Zs (including NBSP) without
stripping. Real policy.clean_text/scope used directly, no fallback. Local type/raw-cap
checks precede policy; local categories overlap real policy (which already includes
Cf). No text permission carve-out. Finite positive exact built-in int/float prices
remain supplied; unconvertibly huge integers now yield BAD_TYPE:price_points rather
than leaking OverflowError. Float pricing retains six-decimal rounding as before.

Count-first/raw-cap/key-resource refusal precedence changes are deliberate policy
hardening, not new owner effect approval. Forbidden classes retain constant suffixes,
precedence SEND>SPEND>EFFECT>NOCREDS, sorted matched key within class. No network,
spending, execution, registry, launch, sending, approval or market-validation path.

Evidence is held privately, not included in the landing tree. Initial RED used
a 43-case delta file (17 failed/26 passed); the final 59-case preimage rerun found
39 failed/20 passed. Later pins are additive. Local Cf-removal equivalence depends
on the repaired shared c30 policy rejecting Cf; it is not a standalone guarantee.
Real Python3.12.14 and unchanged repository conftests used. Full global regression
and external validation NOT_RUN.

## Cardinality-first repair

Two-tier cardinality: declared schema limits retain precedence (root niches
list2000; price_points/channels20, worker_roles12, regulated_flags10). Generic
dicts at most32 keys and lists/tuples at most64 items refuse OVERSIZE:request
before items materialization or reversed traversal. Root niches list alone uses
its declared2000 cap; no exemption for similarly named nested/unknown fields.
Container10000 and depth32 semantics are unchanged; shared references still
count per occurrence. Boundary resource tests now use bounded-branch trees.
Private hostile100k input spies verify refusal before materialization; no
external actions added.

The traversal spy proves only the refusal path, not absence of earlier allocation.
A separate tracemalloc pin starts after creating200k-element hostile inputs and
requires processing peak below100KB for dict/list/tuple. Independent gate measured
repaired peak0.0MB versus old27MB dict/14MB list. Sequence-contained32/33 and64/65
boundaries and root-only list exemption shapes are additionally pinned.
