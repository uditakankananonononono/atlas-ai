## API and schema
`run(request)` returns a plain dict or raises ValueError. Stdlib runtime, real c30 policy.clean_text/scope, no local fallback. Input exactly as_of string, volumes list, optional target_pages(default5000), exact non-bool integer1..100000. Volumes exactly id,title,sections; unique volume ids. Sections id,heading,optional body/source_ref; unique ids globally. Unknown keys/types refuse. Missing body/ref default empty; explicitly supplied nonstrings refuse. Body supports ordinary LF/CR/TAB, refuses other control chars; metadata is single-line. Supplied order retained, caller structures untouched. References preserved verbatim, never fetched; evidence_verified:false on each receipt.

Empty volumes or zero total sections refuses NOSECTIONS. Nonblank body and reference defines eligibility, not authenticity. Missing/whitespace-only body/ref yields `[UNFILLED: heading]` and unfilled_count. Eligible bodies alone enter repetition population: collapse whitespace with split/join; SHA256 each complete200-code-point window at offsets0,50,100,...; count occurrences across the whole document. Any window hash occurring4+ times excludes every eligible body containing it, replaced in its original slot with `[EXCLUDED_REPETITION: heading]`. excluded_count separate from unfilled. If no accepted section remains, UNSOURCED refuses the output.

Only accepted body.strip() code points count; internal whitespace raw. Headings/TOC/refs/placeholders do not count. `estimated_text_pages=(accepted_body_chars+2999)//3000`, never rendered or measured pagination. Output carries estimated_text_pages,target_estimated_text_pages,estimated_shortfall=max(0,target-estimate),estimate_basis_chars3000; no bare target_pages output. Volumes contain id,title,markdown; table_of_contents lists volume_id,section_id,heading; section_receipts record status/unverified ref/accepted chars. Also unfilled_count,excluded_count,target_exceeds_cap,estimate_limit and real policy scope.

## Limits and applicability
Input cap is15,000,000 raw body code points total, at most5,000 estimated text pages at3000 characters each. Targets above the cap accepted numerically but cannot be reached in one call; target_exceeds_cap iff target*3000>15M. No5000+ fulfillment, speed, real pagination or rendered-page claim. Work uses sampled fixed-size windows, memory grows with input; no performance benchmark claimed. Repetition is only an aligned50-step heuristic, can miss unaligned patterns or flag legitimate repetition; hash collision theoretically possible, no filler intent/plagiarism claim. Whitespace collapse is for detection only. Content is supplied, not generated or verified.

No spend/send/post/trade/account/scrape/effect code path, no HTTP/catalog/export/deploy/auth. Six shared standing-rule execution paths therefore absent; AST public-surface pin permits only run, not a purity proof. No policy stub or host internals beyond real policy.

## Refusals
PLAN_REFUSED_BAD_TYPE:<field> for schemas/types/duplicate ids/oversize/target bounds. PLAN_REFUSED_NOSECTIONS for no volumes/zero total sections. PLAN_REFUSED_UNSOURCED for zero accepted sections. Real policy adds EMPTY/CONTROL_CHARS/TEXT_TOO_LONG with PLAN prefix. Section-body/reference blank is UNFILLED, not EMPTY; nonstrings BAD_TYPE.
