# S2.7 / c32.dossier - Person-and-venture dossier

## Source pin
Verbatim excerpt: "critically dig up every single thing about every successful person in any field, every venture, every major news, event".

## What it does
Dossier over SUPPLIED public sources: subject-mentioning sentences bucketed into five dimensions (background, career, ventures, recognition, recent_news), each fact cited to its source URL, with a computed completeness score.

## What it does not do
Never fetches. Public figures, public facts only (TREND_REFUSED_PRIVATE). "Every single thing" is not claimed: completeness is dimensions covered / 5.

## Refusals
TREND_REFUSED_PRIVATE, TREND_REFUSED_EMPTY:sources, TREND_REFUSED_OVERSIZE, TREND_REFUSED_BAD_TYPE:*, TREND_REFUSED_EMPTY:*, TREND_REFUSED_CONTROL_CHARS:*, TREND_REFUSED_TEXT_TOO_LONG:*.

## Limits
MAX_SOURCES = 128; MAX_FACTS_PER_DIM = 8; text <= 200000 chars per source. IC: dimension set, subject-token matching, fact caps and the completeness metric are interpretation choices.
