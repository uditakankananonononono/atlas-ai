# S3.2 static site builder

Independent gate: separate record. Not deployed. Static HTML/CSS strings and local source checks, never premium/taste quality. `visual_quality: unverified` always. No render, pixel inspection, Lighthouse or visual-quality claim. `run(request)` is the only public callable. Python standard library, real `app.modules.c30.policy`; no local fallback.

## Schema and refusals

Required request keys brand/pages, optional as_of. Unknown field at any supported nesting level raises PROTO_REFUSED_NOSPEC:path. Missing required fields NOSPEC:path. Keys deploy, host, hosting, domain, publish, upload and cdn recursively casefold-scanned through dict/list values before schema validation cause canonical policy.check('spend','PROTO') -> PROTO_REFUSED_SPEND, even with false/empty values. Strings are never instructions.

Brand is exactly name, palette, font_stack, scale, base_px. Name nonblank <=120. Palette exactly bg/fg/accent, values #RRGGBB. Font nonblank <=200, allowed chars [A-Za-z0-9 ,'-]; CSS control punctuation and words url/import are unsafe. No free-form CSS. Scale int/float non-bool finite 1..2; base_px int non-bool 12..24. Numeric type/range errors BAD_TYPE:scale/base_px. Unsafe color/font values UNSAFE:css. Body BASE; h3 BASE*scale; h2 BASE*scale^2; h1 BASE*scale^3; spacing BASE*[0.5,1,2,4], rounded to six places and emitted px. Layout CSS is fixed template, not supplied CSS.

Pages must be nonempty list or NOSPEC:pages, max20. Each page exactly slug,title,sections. Slug unique, <=40, regex `[a-z0-9]+(-[a-z0-9]+)*`, output slug.html; invalid/duplicate BAD_TYPE:slug. Title nonblank <=120. Sections list max30, may be empty. Each section:

- hero/text exactly kind,heading,body plus optional images; no cards.
- grid exactly kind,heading,cards plus optional images; no body.
- invalid kind or kind-incompatible field NOSPEC:path.
- heading nonblank after strip <=120; blank BAD_TYPE:heading.
- body string <=5000, blank allowed.
- cards list max12, may be empty; each exactly heading/body, same text rules.
- images optional list default [], max30. Image exactly src plus optional alt. Missing/blank alt becomes a failed image_alt check, not refusal; present non-string alt BAD_TYPE:alt; alt<=200.

Image src must match `[A-Za-z0-9_-]+(/[A-Za-z0-9_-]+)*\.(png|jpg|jpeg|webp|svg|gif)` completely. Any external URL, scheme, protocol-relative/root path, traversal, backslash, query, control char or mismatch refuses WHOLE request UNSAFE:image_src. Non-string BAD_TYPE:image_src. Asset bytes are never read, existence/content never verified, assets_unverified:true. Emitted relative URLs refer to external-to-output asset files; HTML/CSS strings alone do not constitute an asset-complete site. SVG asset safety cannot be established without reading assets; do not interpret the source check as full browser security validation.

Cap excess raises PROTO_REFUSED_OVERSIZE:path (text labels name/title/heading/body/alt/font_stack/slug; list labels use indexed schema paths). Wrong types BAD_TYPE:path. Missing/unknown fields NOSPEC:path. Canonical policy.clean_text validates text/control chars, allowing ordinary newlines/tabs in prose; additional CONTROL_CHARS refusal remains possible. No refusal converts into a success-like error dict.

## Generated source and computed checks

Output sorted plain dict: files, checks, scope, visual_quality, assets_unverified. Files maps style.css and slug.html to strings. Text/attribute contexts use html.escape(quote=True), including title, brand, headings, body, card content, image alt/src. Supplied markup is text, never parsed as executable markup. Each page links shared style.css. h1 is page title once; h2 per supplied section; h3 per supplied grid card. No placeholder/invented heading/content. Empty sections/cards are preserved without new h2/h3.

Local parser inspects emitted source independently of request counts:

- contrast_fg_bg and contrast_accent_bg: sRGB linearization at 0.04045, luminance weights .2126/.7152/.0722, (lighter+.05)/(darker+.05); compare unrounded ratio >=4.5, round output six places. Failed contrast is CHECK failure, not refusal or WCAG conformance claim.
- one_h1 count exactly1.
- heading_order no forward skip >1, first heading starts at1; counts generated headings, not rendered accessibility tree.
- image_alt nonblank string on every emitted img; value contains image/missing counts.
- size_bytes inclusive <=102400 UTF-8 bytes = page HTML plus linked shared CSS. Excludes asset bytes, HTTP/compression/browser cost. Over-budget still returns files and failed check, not refusal.
- no_external_resources local emitted src/href and CSS HTTP(S) scanning, not network verification or complete active-content analysis.
- no_scripts no parsed script tags; escaped literal script text does not count.

Checks records have page,check,pass,value, sorted by page/check. No filesystem writes, network, browser, account operations, mail, spend, posting, trading or deployment in run. Caller must inspect failed checks; output is not a publish approval. Same input yields same sorted JSON, no wall-clock, no input mutation. as_of optional supplied text <=128; default supplied-input. Pure JSON-like acyclic request assumed; this is not a general hostile-object graph evaluator.

## Canonical policy and limits

Uses real policy.clean_text, policy.scope and policy.check only for the recursive spend refusal. No fabricated offline pass: policy.check('offline') would refuse. Standing rules for spend, outreach, fake accounts, autopost, trade and scraping remain, but none has an execution path. No HTTP handler/catalog. public callable test expects run only. Unknown action-like fields cannot grant permission. Output scope explicitly excludes visual quality or WCAG conformance, browser rendering/Lighthouse, image asset contents/existence, deploy/hosting/domain/effects. Static checks do not validate taste, layout, fonts installed on the recipient device, responsiveness, image content, usability or full security/accessibility.
