# c35.s4-7 abroad-fullride-planner

## Scope note

Country/university/scholarship table from sourced public data, filtered to full
rides for international undergrads with no additional written tests, accepting CBSE
marks plus a matching declared test credential (SAT, or IELTS when declared in the
profile). Each row has a source URL and fetch date; coverage is computed and
reported (target 100 countries, achieved N), never claimed. Route `/c35/abroad` is
not mounted (scoped unit).

## Scope

- implemented: `plan_full_rides(payload)` in
  `backend/app/modules/m23_study_abroad/s4_7_abroad_fullride.py` (additive; placement in
  m23 composes `source_freshness.assess_facts`). Filters caller-supplied rows to
  full rides for international undergrads with no additional written tests, accepting
  CBSE marks plus a matching declared test credential. Per-row public https source_url
  and fetched_at; freshness graded by recorded-check age. Coverage computed
  (target 100 countries, achieved N). Pure, stdlib, deterministic; as_of is the
  freshness "now".
- not_implemented:
  - no fetching - rows are caller-supplied from public sourced pages
  - never applies, submits or sends (S4.5 owns prefill) - `APPLY_REFUSED_SUBMIT`
  - no fee waivers or spend (S4.3 owns waivers) - `APPLY_REFUSED_SPEND`
  - freshness is recorded-check age only, never source verification
- data_source: supplied

## Filter

Keep a row iff: `full_ride` AND NOT `requires_extra_written_test` AND `accepts_cbse`
AND a profile-declared credential matches (`profile.sat` present AND row `accepts_sat`,
or `profile.ielts` present AND row `accepts_ielts`). Excluded rows report ordered
reasons: not_full_ride, requires_extra_written_test, cbse_not_accepted,
test_credential_not_accepted. Profile gate: curriculum must be exactly "CBSE" and at
least one of sat (int 400..1600) / ielts (0..9) must be declared.

## Refusals (stable strings)

- `APPLY_REFUSED_SPEND:s4_7_is_a_planner_no_spend` (purchase/spend/pay/fee_payment keys)
- `APPLY_REFUSED_SUBMIT:s4_7_plans_only_never_applies` (submit/apply/send/auto_apply keys)
- `APPLY_REFUSED_NON_PUBLIC:source_url_must_be_public_https`

Note on the source_url check: it is a prefix-and-dot syntax check only - the value
must start with `https://`, be at most 2048 characters, and have a dot in the host
part. It is NOT a publicness guarantee: it does not show the page is public,
official, reachable or verified, and no fetch is ever attempted. The refusal
string keeps its historical name for caller stability.
- `APPLY_REFUSED_PROFILE:curriculum_must_be_CBSE`,
  `APPLY_REFUSED_PROFILE:cbse_plus_sat_or_ielts_required`
- `APPLY_REFUSED_OVERCAP:max_5000_rows`, `APPLY_REFUSED_DUPLICATE:<id>`
- `APPLY_REFUSED_BAD_TYPE:<name>`, `APPLY_REFUSED_UNKNOWN_FIELDS:<where>`,
  `APPLY_REFUSED_EMPTY_FIELD:<name>`, `APPLY_REFUSED_UNSAFE_CHARS:<name>`,
  `APPLY_REFUSED_OUT_OF_RANGE:<name>`, `APPLY_REFUSED_BAD_DATE:as_of`

## Interpretation choices (invented, not in the spec text)

- **Credential-aware test filter.** The source text pairs CBSE with SAT and marks
  IELTS as optional. This unit accepts CBSE plus a declared SAT or IELTS credential.
  The row must accept a credential declared in the profile. With an SAT-only
  profile that excludes IELTS-only rows; declaring IELTS later admits them.
  This is an interpretation choice, not a source requirement.
- Refusal prefix: S4 family prefix is `APPLY` (spec S4 header); S4.7's row names no
  codes, so the codes above are invented per family convention.
- Module placement: no c35 package exists on main; placed in m23_study_abroad to
  compose source_freshness. Route `/c35/abroad` not mounted (scoped unit).
- 5000-row cap, 200-char text limits, 180-day default freshness window are invented
  bounds. "Unlimited US colleges" means no per-country cap, not an achieved count.
- fetched_at is expected to be a zoned ISO-8601 timestamp (explicit offset). It is
  validated as a short string only; unparseable or date-only (unzoned) values grade
  freshness unknown (recorded-check semantics), never a refusal.
