# S1.6 tool-finder-integrator (c31.integrate)

Source pin (verbatim, spec S1.6): "find new ai tools and integrate them".

Does: scores SUPPLIED alternative tools for a use case from supplied
metadata (3 + 2*rating/5 + privacy tier good 3 / caution 2 / toxic 0), picks
the single best, and generates an offline adapter stub plus a deterministic
3-step sandbox test plan for the pick.
Does not: install, download, or call any tool; the adapter stub raises
NotImplementedError until a reviewed implementation exists.
Refusals: FLEET_REFUSED_SPEND:<name> (paid tool) / BAD_TYPE:tools|tool|rating|privacy_tier /
OVERSIZE (>256) / AMBIGUOUS:<a>|<b> (tie at the top) / CONTROL_CHARS:*.
Limits: tools <= 256; rating in [0,5]; tiers {good,caution,toxic};
use_case <= 200 chars.
IC: tie at the top is refused rather than broken silently. Payment refusal
substitutes for spec risk X12.
