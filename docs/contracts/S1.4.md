# S1.4 cognition-benchmark-board (c31.bench)

Source pin (verbatim, spec S1.4): "Superintelligence -AGI -able to completely mimic humans".

Does: records SUPPLIED measured scores over runs for a fixed battery
(reasoning, planning, novelty); reports per-task run count, latest and best
scores, latest pass vs supplied pass mark (>= passes), the measured ceiling
across all runs, and the list of tasks not currently passing (a task with no
runs counts as failing).
Does not: run any model or benchmark itself; no superintelligence, no
mimicking humans - the source phrase is the aspiration this unit measures
toward, and every number here is a supplied measurement, not a claim.
Refusals: FLEET_REFUSED_BAD_TYPE:runs|run|score|pass_mark / EMPTY:runs /
OVERSIZE (>4096) / DUPLICATE:<run_id> / BAD_TASK:<task> / CONTROL_CHARS:run_id.
Limits: scores and pass marks in [0,1]; run_id <= 64 chars.
IC: pass is >=; an unmeasured task reports nulls and joins the failures list.
This unit substitutes for spec risk X8 by keeping claims honest.
