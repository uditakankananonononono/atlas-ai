## Behavior

Request contains exactly as_of/docs (as_of required by validation); docs is a
nonempty list of records containing exactly doc_url and text. as_of is supplied
text <=128 characters, not verified recency. Doc URL <=512 chars; export text
<=2000000 chars per doc, preserved. No aggregate doc-count cap introduced; caller
must apply aggregate request/resource bounds before network/API hosting.

Extract HTTP/HTTPS link candidates from supplied lines; each label is the entire
original line, including spaces/tabs. Common closing prose/Markdown punctuation
.,;!?)]} is trimmed. Normalize lowercase scheme/host, drop fragments, strip
trailing path slashes, remove case-insensitive utm_* query keys. Parse/re-encode
remaining query pairs preserving order and blank values. Preserve path/query case,
ports and non-UTM keys. Reject malformed host/port and credential-bearing URLs.
No normalization of redirect targets, default ports, query order or percent-encoded
path equivalence. Common-punctuation trimming is a heuristic and may trim a valid
URL character; no claim of universal URL grammar correctness.

Index retains first occurrence order and first line label. Dedupe normalized URL
across docs; doc_urls records each pinned origin once. coverage.links_found is
candidate occurrence count; duplicates_dropped is repeats; unknown_kind counts
unique index entries with no matching host keyword.

Host keyword table (substring on normalized hostname, first group wins):
- scholarship: scholarship
- competition: competition, contest, olympiad, sciencefair
- grant: grant
- admissions: admission, college, university
- job: jobs, careers
- unknown: none matched

This is a deterministic supplied-host hint, not eligibility/type verification.
Labels/path keywords do not affect classification.

Waiver block starts at any line containing case-insensitive fee waiver or waiver
request; continues through following nonblank lines, ending before blank line/EOF.
Original internal whitespace/newline format preserved; terminal line separator
before blank delimiter removed. Known {name}, {school}, {opportunity} placeholders
are unique sorted names. Unknown placeholders remain verbatim but are not listed.
Blocks are not deduped, rewritten, personalized or sent. A line containing a trigger
may be prose rather than a real template; result remains a supplied candidate.

## Refusals

APPLY_REFUSED_NOSOURCE: docs absent/empty.
APPLY_REFUSED_URL_NOT_PINNED: Doc URL not exactly one of two pins.
APPLY_REFUSED_BAD_TYPE:<field>: bad request/doc/URL/field type or extra keys.
APPLY_REFUSED_EMPTY:<field>: required text empty.
Shared policy can also raise APPLY_REFUSED_CONTROL_CHARS:<field> and
APPLY_REFUSED_TEXT_TOO_LONG:<field>. Ordinary LF/CR/TAB allowed in export text
via real policy.clean_text(...,allow_ws=True); other controls refuse.

combined app regression performed.

## Frozen output shape

`run()` returns only these four top-level fields. Angle-bracket values below
are typed placeholders, not literal strings in the report. coverage values are
integers. Each index entry has at least one doc_urls item; other lists may be empty.

```text
{
  "index": [{
    "url": <normalized URL string>,
    "label": <original full line string>,
    "kind": <scholarship|competition|grant|admissions|job|unknown string>,
    "doc_urls": [<exact pinned Doc URL string>]
  }],
  "waiver_templates": [{
    "text": <verbatim block string with terminal separator removed>,
    "placeholders": [<name|opportunity|school string, unique alphabetical order>],
    "doc_url": <exact pinned Doc URL string>
  }],
  "coverage": {
    "links_found": <integer candidate occurrences>,
    "duplicates_dropped": <integer normalized duplicate occurrences>,
    "unknown_kind": <integer unique index entries classified unknown>
  },
  "scope": {
    "implemented": [
      "supplied pinned-Doc link index",
      "URL normalization and dedupe",
      "host-keyword classification",
      "verbatim waiver blocks and known placeholders"
    ],
    "not_implemented": [
      "fetching", "live verification", "dead-link detection",
      "opportunity selection", "submission or outreach"
    ],
    "data_source": "supplied exports of two owner-pinned Docs",
    "as_of": <caller-supplied as_of string>
  }
}
```

index order is first occurrence; doc_urls is first origin occurrence with no
repeats; templates follow supplied doc order then block order. Authority formatting
retains explicit ports and brackets around normalized IPv6 hosts. Independent audit
requested additional IPv6/port tests; this child adds those tests without runtime changes.
