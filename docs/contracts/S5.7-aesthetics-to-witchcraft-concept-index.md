## Validation and refusals
A non-dict request refuses BAD_TYPE:request. Recursive key scan normalizes keys
by casefold and hyphen-to-underscore for exact forbidden table matching.
Precedence SEND > SPEND > EFFECT > NOCREDS; sorted table-key tie break.
SEND keys include send/approve/approved/approval/approval_token/smtp/token,
email_send/sender/smtp_host/smtp_port/smtp_user. SPEND keys: pay/purchase/spend/
buy/checkout/card_number. EFFECT: fetch/crawl/scrape/download. NOCREDS: login/
password/username/credentials/otp/api_key/access_token/refresh_token/bearer/
pass/passwd. Recursion scans dict values and list items. No substring matching.
Non-string dictionary keys refuse BAD_TYPE:key; unknown schema keys refuse
UNKNOWN with schema parent field only. No supplied ID/value/path is echoed.
Required shape/date errors refuse BAD_TYPE:field; empty page list refuses EMPTY.
Caps refuse OVERSIZE:field before Unicode text validation across the page list.
Real c30.policy.clean_text validates fields without normalization. Its
TEXT_TOO_LONG refusal is unreachable: every length cap is checked first and
helper limits equal the caps. Tests pin OVERSIZE, cap-removal and reduced-helper-
limit mutants demonstrate why the ordering/limits matter. Other helper refusals
(type, empty, Unicode controls) retain their exact codes. Prefix VENT_REFUSED_.
No policy.check call, adapter or fallback; no action execution path exists.

## Graph
Node key: casefold + whitespace collapse. First supplied original title wins;
duplicate titles merge. Targets not among supplied pages are unread stubs.
Edges distinct by (source,target,kind). Category and link to the same target
count as two labelled edges; repeated identical triples collapse. Degree is
in+out distinct edges, so a self-edge contributes twice. Ranking degree desc,
key asc, top50. Undirected connected components sorted by smallest-key ID;
nodes within each component sorted. Node/edge outputs sorted. Counts computed.
20,000 cap applies to supplied pages, not graph nodes/stubs or universal coverage.
