# Research Scientist tool policy

Module 4 tool workers run only after Module 0 approval, in ephemeral no-network Docker containers with read-only inputs, bounded CPU/memory/time, writable output artifacts, logs, and image/version provenance.

Implemented adapter surfaces: AutoDock Vina-class docking, local ColabFold batch, Galaxy official API workflows, and PyMOL headless scripts. Deployment images must install and pin these tools before enabling routes. Nature and Science are monitored through allowed RSS/abstract metadata only. Legal book/literature connectors are Open Library, Google Books, arXiv, PubMed/PMC, Crossref/OpenAlex, DOAB, and user-owned files. No OceanofPDF/piracy adapter exists.
