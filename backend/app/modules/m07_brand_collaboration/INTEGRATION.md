# Module 7

Tenant-scoped SQL stores brands, immutable partnership events and hashed artifacts. Discovery accepts only public/API/user-supplied sources; it deliberately excludes Sales Navigator and login-driven scraping. Media kits, tier packages, invoices and reports render with WeasyPrint when installed and retain a deterministic HTML fallback. Every outbound collateral/report/invoice action enters Module 0 approval; this package never sends.

Advancement pass: evidence-labelled alignment scores, artifact SHA-256 integrity, immutable event history, period-bound reports, cross-tenant isolation, and deterministic no-LLM fallback.
