# Module 8

Generates reviewable source archives, never a direct deployment. Landing pages include Next.js, Tailwind and a validated, idempotent Supabase waitlist endpoint. Pitch decks use python-pptx when installed and preserve a Markdown fallback. Documentation extracts real FastAPI route decorators, produces OpenAPI/ReDoc/manual/blog artifacts, and hashes each supplied code file as evidence.

Advancement pass: reproducible ZIPs, integrity hashes, evidence manifests, claim provenance, deduplicated waitlist writes, secret-free `.env.example`, accessibility labels, and approval gates for push, deploy, share and publish.
