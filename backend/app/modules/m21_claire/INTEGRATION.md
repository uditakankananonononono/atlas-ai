# Integration
Mount `router`; mark Module 21 implemented. Claire composes Module 20 and controls the user's computer only through an installed local client daemon. Pair the daemon to Atlas with a user-confirmed, expiring challenge and pinned mutual-TLS device certificate. Store device private keys in the OS keystore. The daemon exposes only user-granted capabilities (typing, pointer, browser, files, commands), applies OS permission prompts, previews actions, and shows native on-device approval dialogs for high-risk, irreversible, external, credential, install, delete, command, or deployment actions. Every action and result enters a tamper-evident local audit log with sync to Atlas; support pause/kill switch, per-capability revocation, session expiry, path/domain allowlists, snapshots/undo where possible, rate and budget limits, and secret redaction.

The server sends declarative actions, never arbitrary hidden remote-control streams. Retries cap at 5 and escalate. No piracy, fabricated application content, self-bots/ban evasion, or login-driven scraping. Decision traces show plans, evidence, alternatives, decisions, and failures, not hidden chain-of-thought.
