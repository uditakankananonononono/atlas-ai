# Feature evidence: rows 710-740

Mounted typed endpoint: `POST /v1/modules/17/communication/coaching`.

Each row maps one-to-one to `CommunicationSkill` and `_SKILL_GUIDANCE` in
`communication_coaching.py`. `test_m17_rows_710_740.py` parametrizes every row ID and
name, checking a typed result with observations, questions, rehearsal steps, explicit
review, and no external action. Focused safety tests cover truthful persuasion,
non-diagnostic empathy/cultural coaching, mediation caveats, boundaries, and the
student-authored essay boundary. `test_m17_routes.py` checks the mounted endpoint and
authenticated-owner isolation.

Caveats: these are deterministic coaching/critique workflows, not a generative message
writer. They do not send, publish, impersonate, claim to read emotions, settle disputes,
or substitute for qualified help in unsafe/coercive situations. Presentation design
returns content coaching, not a rendered deck. Public speaking returns rehearsal steps,
not audio/video analysis. Cultural guidance asks preferences rather than applying group
stereotypes. Student work remains student-authored.
