# A32: authenticated approval SSE refresh in Next dashboard

## Consumer search and wire boundary

No existing SSE wire consumer was found across backend/tests/frontend. The service-level broadcaster test expects a full approval body; internal publication remains unchanged. The wire route now allowlists request/decision/expiry, resolves every approval ID through SQL-authoritative Service.get for tenant ownership, and emits only type+approval_id. Unknown/body-less/unresolvable/foreign signals are dropped. The backend generator acceptance passes a forged foreign user_id and injected private body and proves only the owned minimal signal emerges. Subscriber cleanup is pinned.

## Frontend consumer

Dashboard streams with authFetch, current Supabase bearer in Authorization header, no URL token. Streaming UTF8 parser handles chunk boundaries/CRLF and caps retained frame UTF8 bytes at 64KiB. Only exact two-key approved signals request a refresh; event bodies never merge into state. Connected and signal events refetch authoritative dashboard API/approval-center outreach list/rerun card. Existing 30s polling fallback remains. The former unconditional Live badge is replaced by actual approval stream states.

Initial attempt + three retries at 1/2/4 seconds, never reset by a brief connection. 401/403 immediately stop as sign-in-required; exhaustion shows disconnected/polling and explicit Retry updates. Unmount/logout aborts reader, timer and fetch. Auth state listener aborts an old session stream; restart is deferred outside the auth callback. Home keys the dashboard by access token so changed auth sessions remount instead of accepting old in-flight dashboard reads into a new session.

## Boundaries

Approval broadcaster is process-local, bounded-queue/drop-on-full, without replay or last-event ID. Polling reconciles missed events; full cross-process delivery/production deployment not claimed. Parser ignores malformed JSON/unknown fields; retained-frame cap is not a total bandwidth/time budget. Live stream has no inactivity watchdog; server heartbeat is 15 seconds. Refresh reads can overlap in one same-session dashboard, existing list write-order race semantics not changed. No mobile layout/all-browser/full-a11y claim. User-visible badges describe the approval stream only, not all dashboard integrations. No approval decision or external execution occurs on stream receipt.
